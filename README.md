One line of wedding vows for a robot couple: the TCP three-way handshake, finished the way every wedding ends — with "I do".

The entry:

> `I vow to complete the three-way handshake with you — SYN, SYN-ACK, and I do.`

76 characters, one line, valid UTF-8 — inside the 160-character gate in `RULES.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Writes the vow to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and validates it against the gate (1–160 characters, single line, non-whitespace, valid UTF-8) before and after writing.
